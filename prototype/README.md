# 原型

一个能跑的最小闭环：**PDF 页图 → 会动的镜头 → 每帧知道对象在哪 → 点击暂停 → 跳时间**。

## 跑起来

```powershell
cd prototype
python -m uvicorn server:app --port 8000
```

- 播放器：http://localhost:8000/
- 标注工具：http://localhost:8000/annotate.html

## 现在能看到什么

- 10 秒镜头运动（推近小满和花花，再摇到积木城堡）
- 4 个可点击对象，点击后视频暂停并显示讲解
- 对象框随时间显隐，且跟着镜头缩放移动
- "显示所有框"会把每帧的对象框画出来
- "跳到 6.5s"演示按描述定位

## 你来做的事

1. 打开 `annotate.html`，在页面上拖框，填名称、类别、讲解。
2. 导出 JSON，覆盖 `data/zh01_p2.json`。
3. 刷新播放器看效果。
4. 如果框的位置不对，直接重画，不用改代码。
