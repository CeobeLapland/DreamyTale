# 《纸书智伴》功能清单（按优先级）

> **P0** = 不做过不了线；**P1** = 拿分主力，决定名次；**P2** = 有余力才做；**P3** = 彩蛋 / 未来。
> **得分点缩写**：理解=内容理解｜生成=绘本生成质量｜连贯=风格一致+页间连贯｜触控=万物识别｜问答=回答正确性｜检索=视频内检索｜延迟=实时性｜Agent=多Agent协同｜合规=规范与安全｜体验=儿童参与度
> **★** = 出自《一页剧团》GDD，上一轮头脑风暴漏掉、这次补进来的好点子。

## 负优先级：明确不做

| 不做 | 原因 |
|---|---|
| 每页都生成完整视频 | 慢、贵、风格必崩，且违反"纸偶即素材"的一致性策略 |
| 开放域自由聊天 | 儿童安全红线，一票否决 |
| 6 本书全量精做 | 改为 1 本打穿 + 1 本换书证明泛化 |
| 儿童账号 / 社交 / 排行榜 / 付费 | 合规风险，且不加分 |
| VR / AR 头显、定制硬件 | 现场不可控，投入产出比极低 |
| 自研模型训练 | 赛期内不现实，开源方案足够 |
| 超过 5 秒的实时视频生成 | 延迟必然崩，用纸偶和高光镜头组合替代 |

## 相对《一页剧团》GDD，这次新增的四个点

1. **共形映射**：生成时锁原画锚点，把"触控准确率"从检测问题变成标定问题——这是触控得分最稳的做法。
2. **预测式预生成**：按阅读速度和提问历史提前渲染，延迟被摊销而不是被优化。GDD 只有"下一页预取"，这里多一层"预判你会问什么"。
3. **对话式阅读反问**：从"孩子问、AI 答"变成"AI 也会问孩子"，有教育学依据，且天然产出多模态对话历史。
4. **空间引用高亮**：答案除了页码和时间戳，还在纸页与画面上框出那一块，评委可以当场核对。

## 如果只能保三件

1. **指哪问哪 + 带出处**（同时打中触控、正确性、视频检索三个评分点）
2. **涂鸦上台**（全场唯一的"哇"）
3. **书灵 + 降级链**（情绪主线 + 现场不翻车）

第四件才是后台剧团——它不加体验分，但它是"多 Agent 不是包装"的唯一证据。
