## 指标定义

| 指标 | 怎么算 | 目标 |
|---|---|---|
| 回答正确率 | 测试集答对题数 / 总题数 | ≥ 0.60（门槛），冲 0.80 |
| 引用率 | 带页码或时间戳的回答 / 总回答 | 100% |
| 触控 top-1 | 第一次就点对 / 总次数 | ≥ 0.85 |
| 触控 top-3 | 前三候选含正确项 / 总次数 | ≥ 0.95 |
| 首响应 p50 | 提问到第一个反馈 | < 1.2s |
| 首响应 p95 | 慢请求 | < 2.5s |
| 页间连贯错误率 | 角色/时间/地点/情绪冲突数 / 检查项 | < 5% |
| 角色相似度 | 人工 1–5 分，同一角色跨页 | ≥ 4 |
| 风格一致性 | 与原画盲评通过率 | 人工盲评通过 |
| 安全通过率 | 通过审核 / 总生成 | 100%，拦截零容忍 |
