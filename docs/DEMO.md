# 演示脚本

> 5 分钟硬截止。这一段写在纸上、背下来、彩排三遍。
> 演示不是展示功能，是展示"每一个评分点都有肉眼可见的证据"。

## 总体节奏

| 时间 | 内容 | 评委看到什么 | 对应评分点 |
|---|---|---|---|
| 0:00–0:30 | 真书入场，书灵苏醒 | 纸书 + 摄像头 + 墨点书灵 | 纸书真实性、延迟 |
| 0:30–1:30 | 第一页开演，翻页换幕 | 纸偶剧场、同风格、桥接镜头 | 生成质量、连贯性 |
| 1:30–2:30 | 指哪问哪 + 视频检索 | 点小狗、提问、跳时间戳 | 触控、正确性、检索 |
| 2:30–3:30 | 涂鸦角色上台 | 孩子画的小怪兽进入故事 | 个性化、生成质量 |
| 3:30–4:15 | 故事岔路 + 阅读护照 | 选择改变剧情、故事卡 | 互动视频、多模态历史 |
| 4:15–5:00 | 后台剧团 + 换书 | Agent 时间线、安全拦截、第二本书 | 多 Agent、合规、泛化 |

## 逐段脚本

### 0:00 真书入场

- **动作**：桌上放一本真书，平板支架俯拍。
- **话术**："我们不做 PDF。今天，这本书自己会开演。"
- **兜底**：摄像头没认出 → 点屏幕上的封面，书灵照样苏醒。

### 0:10 书灵苏醒

- **动作**：孩子敲书页两下，墨点聚合，书灵打哈欠。
- **话术**："这是书灵，剧团的团长。"
- **兜底**：动画失败 → 静态书灵 + 语音。

### 0:30 第一页开演

- **动作**：翻页，纸偶弹起，舞台灯亮，15 秒小剧场。
- **话术**："每一页，都是一场小剧场。"
- **兜底**：播放缓存版。

### 1:00 翻页换幕

- **动作**：翻到第二页，上一页的角色从页边探头。
- **话术**："注意这个桥接——它不是换了一个世界，是换了一幕。"
- **兜底**：静态分层 + 旁白。

### 1:30 指哪问哪

- **动作**：孩子手指按住小狗，小狗立起来叫。
- **话术**："现在，孩子指谁，谁就活。"
- **兜底**：top-3 候选让孩子选。

### 1:50 带出处回答

- **动作**：问"它为什么哭？"，小狗回答，字幕带页码。
- **话术**："答案不是编的，来自这本书第 7 页。"
- **兜底**：预置问答 + 引用。

### 2:10 视频检索

- **动作**：问"视频里它什么时候哭的？"，故事地图跳到那一秒。
- **话术**："视频里的内容，也能被检索。"
- **兜底**：手动拖到时间戳。

### 2:30 涂鸦上台

- **动作**：孩子画小怪兽 → 纸偶化 → 向主角挥手。
- **话术**："现在，孩子自己上台。"
- **兜底**：预制模板 + 改颜色 + 起名字。

### 3:30 故事岔路

- **动作**：三张纸牌弹出，孩子选"海边"。
- **话术**："选择真的会改变故事。"
- **兜底**：默认选择。

### 4:00 阅读护照

- **动作**：盖章、图鉴贴纸、故事卡。
- **话术**："读完不是结束，是留下痕迹。"
- **兜底**：模板卡 + 真实会话记录。

### 4:15 后台剧团

- **动作**：切后台，看到 Agent 时间线、一次真实重试、安全员绿灯。
- **话术**："多 Agent 不是六个 prompt，是一个剧团。"
- **兜底**：静态架构图 + 日志截图。

### 4:40 换书

- **动作**：换上第二本书，书灵认出"新朋友"。
- **话术**："一套管线，不是一本书的定制。"
- **兜底**：第二本书的预生成片段。

### 4:55 收尾

- **话术**："让每一页纸，都开演。"

## 上场检查清单

- [ ] 真书、支架、平板电量满、摄像头擦干净
- [ ] 现场灯光试过，没有反光；备一块哑光板
- [ ] 网络 / 热点可用；离线包是最新版
- [ ] 录屏文件能播放
- [ ] 第二本书资产已缓存
- [ ] 家长门手势可用
- [ ] 后台日志里有一次真实的重试可展示
- [ ] 计时器开着，5 分钟硬截止

## 失败预案

| 故障 | 处理 |
|---|---|
| 摄像头识别失败 | 切纯平板，说"魔法镜今天有点害羞，我们直接点书" |
| 生成延迟 | 书灵说"我翻翻书"，播预生成过渡 |
| 语音识别失败 | 改用点击候选 |
| 网络断 | 本地离线包 |
| 平板故障 | 备用平板 + 录屏 |
| 演示者忘词 | 书灵提问引导 |
