# 路线图

> 按依赖排序，不按日期。每个阶段只有一个"必须做完才算过"的目标。
> 任务粒度在 [PLAN.md](PLAN.md)，功能细节在 [功能清单](纸书智伴_功能清单.md)。

## 一眼看全

```
Phase 0 契约      →  Phase 1 一页能演  →  Phase 2 交互三件套
                                              ↓
Phase 5 答辩  ←  Phase 4 泛化与稳定  ←  Phase 3 后台与合规
```

Phase 3 和 Phase 4 可以并行；Phase 2 内部三条线也可以并行。

## Phase 0：契约与资产审计

**目标**：让三个人能不互相等就开始写。

- 交付：`contracts/book_asset.schema.json` 可选字段先跑通、6 本书资产审计、选定主攻的 1 本
- 完成标志：A 能按 schema 导出一页 JSON，B 能按 schema 找到分层文件，C 能按 schema 画出热点
- 对应功能：全部 P0 的前置

## Phase 1：垂直切片，一页能演

**目标**：真书放上去 → 书灵醒来 → 一页纸偶演起来 → 点一下有反应。

- 交付：页面识别 + 单应、1 页分层、1 个角色纸偶、书灵、基础 TTS
- 完成标志：端到端 3 分钟不崩；换角度还能认出来
- 对应功能：P0 #1–#7、#16、#27

## Phase 2：交互三件套

**目标**：把三个记忆点做出来。

- 2a 指哪问哪：热点索引 + 回答 + 页码引用 + top-3 反问
- 2b 涂鸦上台：画 → 纸偶化 → 进 2 个场景
- 2c 故事岔路：三张牌 → 换景 → 回到主线
- 完成标志：点 10 次对 8 次；涂鸦角色跨场景不变形；岔路能回到主线
- 对应功能：P0 #12–#18、P1 #2、#8、#9

## Phase 3：后台与合规

**目标**：让评委看见"多 Agent 不是包装"。

- 交付：编排器事件流、后台剧团 UI、延迟 HUD、安全员拦截记录、来源清单
- 完成标志：后台能看到至少 3 个 Agent 协作 + 1 次真实重试 + 1 次安全拦截
- 对应功能：P0 #21–#23、#30；P1 #16、#18、#24

## Phase 4：泛化与稳定

**目标**：换一本书也能跑，断网也能演。

- 交付：第二本书资产、离线包、降级链、缓存、5 分钟脚本彩排
- 完成标志：第二本书 30 分钟内完成资产化；拔网线还能演完 3 页；脚本连跑 3 次
- 对应功能：P0 #24、#25；P1 #19–#22、#26

## Phase 5：答辩准备

**目标**：8 分钟讲清楚，任何问题都有答案。

- 交付：项目说明书（≤20 页）、演示视频（≤5 分钟）、Q&A 卡片、评分点证据页
- 完成标志：5 分钟陈述不超时；每个评分点都能指到一个界面或一段日志
- 对应功能：DEMO.md 全流程

## 固定动作

| 频率 | 动作 | 产出 |
|---|---|---|
| 每天 | 各人更新 PLAN.md 自己那几行 | 看板 |
| 每周三 | 合练一次完整 5 分钟 | 卡点清单 |
| 每周五 | 更新 EVAL.md 跑分 + 清卡住区 | 数字与结论 |
| 每次引入素材/模型 | 当天登记 SOURCES.md | 合规清单 |

## 阶段铁律

1. **Phase 1 没过，不许开 Phase 2。** 一页演不起来，三件套全是空谈。
2. **任何阶段超范围，先砍功能，不加人天。**
3. **每阶段结束跑一次 DEMO.md 对应段落**，不能等到最后才彩排。
