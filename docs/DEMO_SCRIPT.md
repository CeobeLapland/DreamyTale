# 5 分钟演示脚本（录制用）

目标：一条 5 分钟、可剪辑的完整链路，现场只操作阅读器 `/reader/`，不切终端。

## 录制前 3 分钟

- 起服务：双击 `start.bat`，或 `.\start.ps1`；没有网络时用 `.\start.ps1 -Offline`。
- 打开 `http://127.0.0.1:8000/reader/`，选“中文绘本01”，确认能播放、能对话。
- 若要用无卡问答：确认 LM Studio 已加载 `qwen/qwen3.5-9b`；没开就避开无卡问题。
- 刷新页面清空对话；关闭通知；浏览器缩放到 100%；录制 1080p，光标可见。

## 时间线

### 0:00–0:25 开场
- 画面：书架六本 + 阅读器主界面。
- 口播：纸书智伴不是把绘本做成视频，而是保留纸书，让每一页可播放、可问、可点、可核对。

### 0:25–1:20 播放与互动视频
- 点播放，停 5–8 秒，展示页动画、字幕、旁白。
- 打开“视频版本”，切一次 I2V 变体再切回 canonical（zh-01 / en-01 有外部动画版）。
- 勾选“视频物体”，翻到第 2 页，点“积木城堡”：展示暂停与“你点到的是……”；点“继续故事”回视频。
- 口播：视频不是黑盒，每个物体都来自页面文字层/热点。

### 1:20–2:30 语音与触控
- 说“暂停”，再说“继续”。
- 说“跳到他们搭好城堡那一页”，展示 seek 到第 2 页。
- 问“他们在搭什么？”，展示 strong 答案 + 页码/框/原文；点“依据”，再回视频。
- 口播：如果没听清，系统会先复述确认，不硬猜；答不到会给引导。
- 可选：故意含糊说一句，展示“不太确定，请再说一遍”。

### 2:30–3:30 生成链路与多 Agent
- 右栏切“生成链路”：14 阶段、OCR/VLM/Story 耗时、provider/model、缓存命中、Critic 0 条提醒。
- 口播：离线内容工厂每本书跑一次；在线 Conductor 每次请求选工具，Turn/Trace 可复盘。

### 3:30–4:15 人工修正与评测
- 切“审核修正”：当前页文字块/热区/问答卡；改一个字段并保存。
- 口播：自动值保留、人工值优先、冲突入队，append-only 可审计。
- 切“评测”：328 用例、315 通过、qa 116/117、意图路由 328/328、证据率 77%、分 kind p95。

### 4:15–5:00 通用性与收尾
- 回书架，选“英文绘本01”，播放 5 秒，展示同一套链路跑英文书。
- 口播：断网仍可阅读/问答/点击；`-Offline` 一键切换；来源清单与说明书在 `docs/`。
- 结束语：把“读一本书”变成“和这本书对话”，并且每句话都有依据。

## 备用方案

- 模型没开：无卡问答会返回 guide；改用问答卡问题，或重启 LM Studio 后再录。
- 网络断/首次 TTS 慢：提前把常用问题问一遍预热缓存；或 `-Offline` 用浏览器朗读。
- 视频不播放：直接打开 `data/books/zh-01/derived/video/final.mp4` 备用片段。
- 热点点不中：确认“视频物体”已勾选、停在第 2 页，点“积木城堡”官方目标。

## 口播注意

- 不念内部术语（kind / tier / bbox），说“动作 / 回答档位 / 依据框”。
- 每次点击前停 1 秒，方便剪辑；语速放慢，句子短。
- 先彩排一遍，确认字幕、音频、热点与页面都在预期位置。
