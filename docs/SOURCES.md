## 隐私

- 不采集真实姓名、生日、学校、面部特征
- 语音 / 图像日志脱敏存储，仅用于本队调试与评测
- 家长门提供"删除本次记录"
- 赛后按通知删除

## 生成内容边界

- 不生成暴力、恐怖、色情、歧视、危险行为
- 不生成"离家出走""跟陌生人走"等可模仿行为
- 不开放自由聊天，回答限定在绘本世界与年龄适配知识
- 不确定时诚实："书里没有讲，我们可以一起看看下一页。"
