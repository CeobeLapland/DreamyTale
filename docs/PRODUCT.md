# 产品定义

> 一页纸。改这一页需要三个人都同意。

## 一句话

孩子把一本真书放在平板支架下，摄像头认出页面，书里的书灵醒来，把这一页变成一座纸偶小剧场。孩子翻页换幕、点谁谁活、指哪问哪，还能画一个角色让它上台。

## 不是什么

| 常见做法 | 我们 |
|---|---|
| 上传 PDF 生成视频 | 真纸书 + 摄像头，纸书是舞台 |
| 每页文生视频 | 分层纸偶实时演 + 少量高光镜头 |
| 打字聊天 | 手指 + 语音，指哪问哪 |
| 多 Agent 藏在后端 | 后台剧团可视化，评委看得见 |

## 三个记忆点

1. **真书入场**：纸书是舞台，摄像头是魔法镜，不是 PDF。
2. **指哪问哪**：点小狗，小狗立起来说话；答案带页码和视频时间戳。
3. **我的涂鸦上台**：孩子画的小怪兽，下一幕真的走进故事。

## 用户

- 3–6 岁：被陪伴、被回应、不害怕 → 书灵引导、短句、慢语速、无失败惩罚
- 6–8 岁：主导、探索、成就感 → 故事岔路、魔法口令、万物图鉴
- 家长：孩子愿意读、内容安全 → 阅读报告、家长门、可删除
- 评委：30 秒看懂、5 分钟记住 → 每个评分点都有肉眼可见的证据

## 本版范围

1 本绘本 · 3 个跨页 · 2 个角色 · 1 次涂鸦上台 · 1 个故事岔路 · 1 套后台可视化 · 第 2 本书证明泛化。

## 不做

- 6 本书全量精做
- 每页完整文生视频
- 开放域自由聊天
- 儿童账号 / 社交 / 排行榜 / 付费
- VR / AR 头显、定制硬件
- 自研模型训练

## 评分点映射

| 评分点 | 我们的证据 |
|---|---|
| 内容理解 | OCR + VLM 结构化输出，六类字段可查 |
| 绘本生成质量 | 原画分层纸偶 + 3–5 个高光镜头 |
| 风格一致 / 页间连贯 | 角色卡 + 舞台监督 + 桥接镜头 |
| 触控万物识别 | 单应映射 + 热点索引 + top-3 反问 |
| 语音问答 / 视频检索 | 带出处回答 + 镜头索引 + 故事地图 |
| 交互延迟 | 纸偶实时 + 预测式预生成 + 延迟 HUD |
| 多 Agent 协同 | 后台剧团时间线 + 真实重试 + 安全拦截 |
| 规范合规 | 安全员 + 来源清单 + 预生成披露 + 家长门 |
