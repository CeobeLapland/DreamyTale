## 文档承诺 vs 实际落地

01-架构里写的设计，逐条对账：

- **页指纹** —— 文档里是"延迟地基"，代码里 0 行
- **三级召回（拼音 → 向量 → 结构）** —— 只做了向量那一级，而且弱模型下召回很差。为了绕过它，我加了"字面闸门"和"单锚点"两处补丁。**拼音和结构检索一行没写**
- **两级缓存（书级离线 + 页级实时）** —— 0 行
- **失败即降级** —— 部分做了（qa 三档），但 seek/touch 失败只有一句提示
- **多 Agent 流水线** —— 0 行，只存在于文档
- **风格闸门** —— 0 行
- **会话状态** —— 做了，但 **先漏了"qa 限定当前页"**，导致第 2 页的问题被最后几页的段落回答。这是文档里写了、实现时忘了的典型

## 我这几天错在哪（三条，都是判断失误）

**一、把"能立刻跑"当成了目标。**

零依赖、可离线、不需要模型——这些在骨架期是对的，但我把它当成了默认优先级，结果在知识层用规则硬凑，凑了三次全失败（0005 记着）。**模型不是可选项，是这个系统的组成部分**，这句话我应该在第一周就承认。

**二、拿补丁冒充设计。**

单锚点匹配、字面闸门、叙事层优先——这些都是在 L2 检索上打补丁，而不是实现文档里的三级召回。补丁本身不算错，错的是**补完之后没有回头改文档**，于是文档和代码变成两套东西。

**三、优先级排反了。**

qa 只占 328 条里的 117 条（36%），而"互动视频生成"是赛题四项任务之一。我却花了两天在 qa 上调参。**该先做生成的骨架，再回来抠问答。**

还有一个自欺欺人的细节：`audit` 工具之前对每本书都报 "✓ 页识别"，其实页识别一行代码都没有，只是页图存在。**报了却做不到的检查，比没有检查更糟。** 已经改掉了。

## 纠偏：接下来按赛题权重排

**第一优先 · 生成链路骨架**
先不追求画质，先把编排跑通：书页 → 分镜稿（LLM）→ 关键帧（占位/文生图）→ 图生视频（占位）→ TTS → 合成 → 写回 `shots.jsonl`。同时把风格参考、跨页状态卡、trace 落盘。
没有视频模型也能做完 60%——**编排、提示词、契约、可复现**这些不依赖模型。

**第二优先 · 语音与触控**
ASR/TTS 接上（本地 whisper.cpp 或云端），前端换麦克风按钮。触控用开放词表检测 + 点击命中。
这两条是赛题硬要求，不做就是缺项。

**第三优先 · 页识别**
翻页跟随是演示最直观的"哇点"，也是页指纹唯一的用途。OpenCV 一装就能做，一天能出数。

**最后 · 问答质量**
等有 GT（golden set 标注）之后再调，否则全是玄学。
